# Introduction
Synthetic behavior-control fixture for a systematic review structure.

# Methods
The search strategy used prespecified eligibility criteria. Two fictional reviewers
screened records, with disagreement adjudication. Risk of bias was considered.

# Results
Six synthetic studies met the inclusion criteria. No real literature search was run.

# Limitations
This is a format example and provides no pooled clinical or scientific evidence.

# Conclusion
The fixture exercises review structure without claiming scientific completeness.
