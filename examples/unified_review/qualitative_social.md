# Introduction
Synthetic behavior-control fixture about experiences of learning.

# Methods
Purposive sampling recruited 18 participants for interviews. Informed consent
and ethics review were described for this fictional study. A thematic analysis
used a reflexive coding process. No hypothesis test was performed.

# Results
Participants described contrasting experiences. These are illustrative themes,
not a population prevalence estimate.

# Limitations
The selected interviews cannot establish population-wide representativeness.

# Conclusion
The example illustrates qualitative interpretation rather than causal estimation.

# References
No genuine participant testimony is included.
