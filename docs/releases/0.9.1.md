# Scientific Reasoning Auditor 0.9.1 / Node adapter 0.2.1

This patch publishes the historical-reference comparison work in the Python
source distribution and npm archive. The engine's numerical decision rules,
CLI/API names and manuscript read-only behavior remain unchanged.

## Install

```bash
python -m pip install --upgrade "scientific-reasoning-auditor[toolkit,logic,research,pdf]==0.9.1"
npm install scientific-reasoning-auditor@0.2.1
sra capabilities
```

The npm adapter requires a separately installed Python engine. Optional Python
backends require the corresponding extras. Base installation stays dependency-free.

## Included comparison material

- `tools/evaluate_published_reference.py`: explicit download and offline run modes.
- `benchmarks/pilots/published-reference-20261116/`: frozen protocol, source-format
  clarification, first JSON/Markdown reports, execution-attempt record and separate
  historical posthoc source notes.
- The npm archive additionally carries citation metadata and comparison/release
  documentation. The Python wheel installs the engine; the comparison script is
  available in the Python source distribution, npm archive and GitHub checkout.

To reproduce the historical measurement, use a separate environment containing
the pinned public **0.9.0** engine, following the bundled benchmark README.
Running the comparator against another engine version is refused. Original
licensed data, codebook and wheel are preserved in the
[reference-validation release](https://github.com/Furox-Art/scientific-reasoning-auditor/releases/tag/reference-validation-20261116).
No original first-result bytes or historical labels have been changed.

## Observed historical results and limits

The selected psychology sample retains 1120 statistical results in 48 source
author-key groups. Coverage is 672/1120 (60%); 448 cases abstain, including
15 reference errors. Reference-frame recall is 34/49 (69.4%); decided precision
is 34/54 (63.0%), with 20 reference-relative false alarms. These are measurements
of the pinned 0.9.0 engine, not new measurements of 0.9.1.

This is retrospective conditional agreement using third-party statistical strings.
It does not establish whole-paper correctness, SRA extraction accuracy or
representative multi-field/held-out performance. Full original articles were
unavailable and were not read. No new human labels or independent scientific
expert validation were collected. Historical reviewer identities and row joins
were not independently re-adjudicated. Source credit and CC BY 4.0 attribution
are retained in the bundled comparison documentation.

## Release validation

The exact release tags run Python, Node and MCP regressions and enforce 100%
runtime statement coverage. Python distributions are built twice and compared,
then checked against strict source/runtime inventories and an isolated install.
The npm package contents are inspected before publication. These software checks
do not measure general scientific validity.
