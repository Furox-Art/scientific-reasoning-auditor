# Python 0.11.0 / npm 0.4.0

Unified Markdown now opens with short English sentences that state execution
outcomes and unresolved review needs. The natural presentation uses a compact
criteria table; the technical presentation retains full criterion procedures.
Both retain module findings, source evidence, calculation results and caveats.
Manuscripts and structured numerical results are unchanged.

Choose `sra review paper.md --report-style natural|technical`,
`review_markdown(report, style="natural")`, or Node's `reportStyle` option.
MCP's opt-in `report_style` adds a bounded, path-scrubbed `readable_report`;
its default structured response remains unchanged. npm requires Python 0.11.0.

Execution success is not scientific validity. Criterion verdicts remain
NOT_ASSESSED; mathematical verdicts remain conditional on supplied inputs and
assumptions. This release does not add human reference labels, representative
scientific-error validation, authorship detection or AI-detector guarantees.
The existing reasoning ruleset remains 0.10.1; new method checks are separately
identified in toolkit adapter bounded-toolkit-5.

See [presentation and compatibility](../REPORT_STYLE.md).


Four scoped method-audit kinds are included in this prepared, unpublished release:
`novelty_comparison`, `literature_search_audit`, `measurement_agreement`, and
`question_method_alignment`. They compare supplied literal evidence, search
records and paired measurements. Overall scientific adequacy remains NOT_ASSESSED;
no search execution or global originality/validity certification is performed.
See [method audit contracts](../METHOD_AUDITS.md).


Evidence mappings now accept explicit offsets; ambiguous unselected occurrences
abstain. Optional selected comparator/reference sets expose missing known inputs.
Paired measurement agreement can use confidence-aware bounds via SciPy instead
of only point estimates. These extensions retain general scientific abstentions;
the advanced synthetic fixture deliberately contains evidence gaps and uncertain
agreement. No additional tool kinds or scientific-quality score are introduced.
