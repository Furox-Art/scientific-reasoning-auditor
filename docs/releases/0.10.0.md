# Scientific Reasoning Auditor 0.10.0 / Node adapter 0.3.0

Reported-statistic checks now support declared one-sided t/z tests and positive
fractional degrees of freedom. Signed statistic rounding is preserved. Unknown
test direction or unresolved df precision abstains rather than guessing.

```bash
python -m pip install --upgrade "scientific-reasoning-auditor[statistics]==0.10.0"
npm install scientific-reasoning-auditor@0.3.0
```

The Node package requires a separately installed Python engine. These options
require Python 0.10.0. CLI, Python, Node and MCP use the same toolkit validator.
Manuscripts remain read-only and results go to separate reports.

## Explicit context

For t/z, `alternative` is `two-sided`, `greater`, `less` or `unknown`.
For F/chi-square, only `greater` and `unknown` are supported. Existing inputs
without a direction retain their previous defaults, exposed as defaults in the
report. No direction is selected by looking for a better p-value match.

Df may be decimal strings in [1e-6, 1e6]. Fractional df default to unknown
precision; `df_precision: exact` is required before numerical calculation.
Explicit `rounded` or `unknown` precision abstains. Corrected df are caller
inputs; correction selection, derivation and suitability are unverified.
Declared exact decimals that the float backend cannot preserve also abstain;
support is limited to exactly representable df such as .5 or 10.5, not 1.3.
Statistic interval endpoints are converted outward. These guards do not prove
a rigorous backend probability error bound.
Source-prepared candidates explicitly require direction and df confirmation.

## Reproducibility and limits

The frozen numerical protocol selects 24 NIST-derived distribution-table cases
and eight separately marked synthetic controls. The offline comparison preserves
every case, expected/actual status, runtime source hashes and environment.

```bash
python tools/evaluate_statistical_context.py --out reports/context-controls
```

This script and reference material are in the Python source distribution and npm
archive. The Python wheel installs the engine. NIST integer-df tables do not
validate all fractional-df calculations; separate analytic unit controls cover
selected cases. No representative whole-paper accuracy, new human labels or
independent scientific expert validation is claimed. The historical published
0.9.0 first report remains unchanged and is not rescored.
