# Scientific Reasoning Auditor 0.9.0

Python engine **0.9.0** and Node adapter **0.2.0** publish the source-bound
scientific inspection work developed in PR #8. English reports are separate
from read-only manuscripts. This remains alpha research software with explicit
unsupported cases and abstentions, not independent scientific expert validation.

## Included developments

- Unified review with six discipline profiles, declared study-type applicability,
  source identity, module execution states and a 43-criterion evidence matrix.
- Restricted Z3 logic, SymPy identities/calculus, Pint units and SciPy raw-data,
  regression, multiple-testing and rounding-aware reported-statistic checks.
- Source preparation, local citation-context retrieval, CSV/SVG inspection,
  supplied-source overlap, caller-mapped protocols and checklist evidence.
- Declared-DAG backdoor checks, bias evidence worksheets, prospective power,
  fixed/random meta-analysis with modified HKSJ intervals, Bayesian chain
  diagnostics, ML split/preprocessing manifests and Crossref update metadata.
- Supplied-covariance GLS, CR1/CR2/CR3 regression, binary missing-outcome bounds,
  one-group-intercept REML, exhaustive null-imposed wild cluster bootstrap and
  balanced equal-size Gaussian cluster-mean power. These are bounded conditional
  calculations; general mixed models and other clustered designs remain open.
- Frozen discrepancy evaluation accepting separately obtained caller-declared decisions,
  explicit false alarms/misses/abstentions, four-label reviewer agreement,
  paper/group strata and descriptive group-omission sensitivity.
- Offline reviewer/adjudicator packet tools, the licensed two-paper feasibility
  recipe and explicit two-run analysis replay in a pinned, already-local Docker
  image. These tools are in the GitHub source archive and do not execute
  automatically during manuscript review or through the MCP server.

## Installation and interfaces

```bash
python -m pip install --upgrade "scientific-reasoning-auditor[toolkit,logic,research,pdf]==0.9.0"
npm install scientific-reasoning-auditor@0.2.0
sra capabilities
```

The Node package drives the separately installed Python engine. Base Python
installation stays dependency-free; requested backends require the corresponding
extras. Python 3.11 or newer and Node 18 or newer are supported. MCP setup,
examples and source-checkout tools are documented in the GitHub source release.
Existing CLI/API names and default offline/model-consent behavior are retained.

## Validation and scientific limits

The release workflows test the exact tags before registry publication, including
Python, Node and MCP regressions, 100% Python statement coverage and synthetic
controls. PyPI distributions are independently built twice and compared, then
checked against complete source/runtime inventories and an isolated installation.
These are software checks; coverage does not measure scientific accuracy.

The small real-paper packet has no genuine returned human labels and is not a
representative validation corpus. Human reviewer identity, expertise and blinding
are not authenticated. Retrieval overlap, numerical agreement and supplied
evidence records do not establish semantic support, authentic data, causal
assumptions, whole-paper correctness or adequacy across every scientific field.
Read the per-method documentation for model assumptions and numerical limits.
