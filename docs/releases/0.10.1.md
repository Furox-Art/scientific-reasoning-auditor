# Python 0.10.1 / npm 0.3.1

The inspection preparer previously missed separately printed degrees of freedom,
uppercase P, common chi-square notation and later triplets in a paragraph.
It now retains every supported literal triplet with its exact source offsets
and quote. Unicode minus signs are normalized only inside the proposed numeric
input, never in the manuscript. Invalid or incomplete quantities remain explicit
candidates; unresolved p-values elsewhere in the same paragraph stay visible.

All proposed directions and df precision remain unknown until explicitly
confirmed. Chi-square-looking notation does not establish Pearson's test,
an exact null reference, unadjusted p-values or an appropriate statistical model.
Preparation never executes checks. Explicitly executing an unchanged draft
abstains. CLI, Python, the Node adapter and MCP share the same preparer.
The new notation behavior requires the Python 0.10.1 engine; npm is an adapter.

```bash
sra prepare-inspection examples/statistic-preparation.md --out reports/prepared
```

Eleven focused Python regressions and real Node/MCP transport controls exercise
source offsets, separate df, multiple results, supported glyphs, unknown
assumptions, incomplete/ambiguous values, code fences and batching/size bounds.
Percentage, range, uncertainty and expression suffixes remain unresolved cues
rather than truncated scalar p-values. Long malformed whitespace is covered by
a whole-path runtime budget check; both statistic and plain-heading matching
avoid the observed quadratic rescanning.

The separate source-checkout follow-up under
`benchmarks/pilots/statistic-preparation-20261116/` preserves a frozen post-hoc
development protocol and three literal source controls from one real paper.
Its conditional replay is a mathematical scenario, not confirmed paper errors
or an independent held-out error-detection evaluation. Original 0.10.0 pilot
results and article snapshots remain unchanged. Human reference labels and
representative multi-field scientific-error validation remain outstanding.

Verified on Windows/Python 3.15.2: 918 Python, 31 Node and 51 MCP tests;
100% runtime statement coverage. The updated twelve-source sweep yields three
drafts from one paper. All three unconfirmed checks abstain; an explicitly
supplied mathematical scenario gives two agreements and one conditional
discrepancy. No confirmed paper-error labels or accuracy estimates were created.
