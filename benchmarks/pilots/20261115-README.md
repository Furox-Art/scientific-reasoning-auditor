# Reported-statistics feasibility packet — 2026-11-15

Prepared sources and blank human-review forms only. **No actual reviewer labels,
automatic predictions or scientific-error accuracy estimates were generated.**
The two included papers are a convenience development sample from one journal,
not a representative multi-field or held-out validation cohort. Four cases are
correlated within two papers; the effective independent unit is not four papers.

## Selection and scope

An initial four-paper selection was recorded before any numerical auditor run.
The first two eligible narrative statistic/df/p triplets per paper were selected
in body order. Table cells, captions, abstract and references were excluded; this
clarification was made during manual eligibility inspection, not preregistered.
Source discovery used reported-statistic search results and availability, so
sampling was not outcome-blinded. No selection used computed auditor decisions.

| Article | Decision | Reason / selected units |
| --- | --- | --- |
| Henry et al., DOI 10.1371/journal.pone.0125124 (PMC4404251) | Included | First two narrative F/df/p triplets; PDF page 7 |
| von Merten et al., DOI 10.1371/journal.pone.0097244 (PMC4016290) | Excluded | Permutation F tests / explicitly corrected later chi-square p values do not fit the ordinary parametric target |
| Plant-Pollinator Interaction Rewiring, DOI 10.1111/ele.70293 (PMC12794140) | Excluded | No eligible complete triplet located in main-body narrative; supplements were outside selection scope |
| Virta et al., DOI 10.1371/journal.pone.0126497 (PMC4427493) | Included | First narrative chi-square and t triplets; PDF page 3 |

The target is conditional reported-statistic/p consistency with display rounding,
not overall paper correctness, appropriate test choice, causal validity, clinical
benefit, image/data authenticity or an allegation about authors. Questionable
tail conventions, corrections and exact/permutation reference distributions must
lead to an explicit mapping concern, uncertain or not_applicable judgment.
The t target is two-sided by convention; author sidedness has not been verified.
Psychology methods mention Greenhouse-Geisser corrections, and the clinical
demographic paragraph mentions Fisher exact tests alongside chi-square tests.
Reviewers must resolve applicability from the full context, rather than assume
that a calculated discrepancy is necessarily a scientific reporting error.

## Contents and handling

- Give only `reviewer-A.zip` to the first reviewer and `reviewer-B.zip` to the
  second. Each contains both complete original PDFs, original JATS XML, full
  normalized front/body/back text, article-specific attribution/license records,
  instructions, contextual cases and a separate blank `review-sheet.json`.
- Keep `organizer/` private until both independent reviews have been returned.
  It contains the frozen executable manifest, selection/mapping records, a blank
  combined label template and an empty adjudication template. There are no
  automatic predictions in either reviewer archive or organizer directory.
- Do not change source files. XML/text normalization flattens inline notation;
  the original PDFs preserve the typesetting, tables and figures. Supplements
  are linked from the articles but are not bundled or claimed to have been read.
- SHA256SUMS covers every other file in its archive. Source hashes also bind
  the exact downloaded XML/PDF bytes; manifest hashes bind the normalized text
  and manually mapped cases. These detect changes, not source authenticity.
- No invitations were sent; no human reviews have been conducted or verified.

The original articles are credited to their named authors, with DOI/publisher
links and CC BY 4.0 links in each source index. Original PDF/XML bytes are
unchanged. Normalized text and case-context excerpts are derived materials;
inline formatting is flattened. No author endorsement is implied. License
evidence is article-specific, not inferred solely from public availability.

## Rebuild from the source checkout

The exporter is an **offline source-checkout tool**, not a new Node/MCP method.
Install the checkout with `python -m pip install -e .`. Download the two included
XML and PDF files using `xml_url` / `pdf_url` in
`benchmarks/pilots/20261115-selection.json` into a separate directory named
`sources/`, as `PMC4404251.xml`, `PMC4404251.pdf`, `PMC4427493.xml`,
`PMC4427493.pdf`. Preserve binary bytes. Updated server snapshots will fail
the frozen hashes; record a new cohort/version instead of replacing this recipe.

```bash
python tools/error_review_pack.py build --sources sources --out pilot-20261115.zip
```

The exporter validates every original hash, full text, quote and structured
specification before creating output. It does not run numerical backends.
ZIP entries have fixed timestamps and sorted names. Rebuilds with the same
Python/zlib environment and source bytes are byte-identical; cross-zlib ZIP
compression identity is not promised. Preexisting outputs are never overwritten.
The 2026-11-06 legacy preregistration and its frozen inputs remain unchanged.

## After actual independent reviews

Each reviewer fills their own ID, all four labels and rationales (20-2000
characters). Allowed labels: error, no_error, uncertain, not_applicable.
Neither uncertain nor not_applicable becomes a negative label.

If decisions differ, obtain an actual third adjudicator, distinct from both
reviewers. In a copy of `organizer/adjudications-template.json`, add records
of the form `{"id":"CASE_ID","reviewer_id":"ACTUAL_ID","label":"LABEL",
"rationale":"ACTUAL_RATIONALE"}`. Do not submit these literal placeholders.
Preserve schema and manifest hash. A supplied adjudication also overrides an
agreement, consistent with the existing evaluator contract.

```bash
python tools/error_review_pack.py merge --manifest organizer/manifest.json --reviewer-a returned-A.json --reviewer-b returned-B.json --adjudications completed-adjudications.json --out actual-labels.json
```

Omit `--adjudications` only if all cases agree. Blank, malformed, duplicate,
incomplete, wrong-manifest/slot and unresolved disagreement records are rejected.
Pseudonymous identities and declared independence are not authenticated.
Lock returned labels before inspecting any automated decisions, then run:

```bash
sra benchmark-errors organizer/manifest.json --out results/run
sra evaluate-errors organizer/manifest.json results/run.json actual-labels.json --out results/evaluation
```

This pilot can test the collection workflow and expose mapping problems.
It cannot establish general error detection accuracy. Representative sampling,
genuine independent labels, verified mappings, preregistration and an analysis
of within-paper dependence remain necessary before broader performance claims.
