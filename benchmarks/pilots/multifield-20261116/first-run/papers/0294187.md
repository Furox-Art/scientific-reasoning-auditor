## candidate\_7: statistic (line 71)
The RNA-seq analyses identified 304 gene transcripts which were upregulated significantly and 172 which were downregulated significantly upon Tet3-silencing (p&lt;0.0001; see S1 and S2 Tables in S1 File respectively) and these data are available at NCBI under GEO accession number PRJNA1035523. To identify functional pathways which might be regulated by TET3 in these neuronal cells, we analysed differentially-expressed genes, identified using a (less stringent) differential expression cut off of false discovery rate (FDR) &lt;0.05, using the Ingenuity Pathway Analysis (IPA; Qiagen) software. This identifies canonical pathways and calculates corresponding activation z-scores for these pathways, based on both the number of genes identified within a pathway and the direction and magnitude of their change, where an absolute z score of &gt;2 is considered significant. “Oxidative Phosphorylation” (OxPhos) was identified as the most significantly downregulated canonical pathway (z-score = -7.147, p = 5.19E^(-12)). The other significantly downregulated pathways (with a z-score of &lt;-2 and p&lt;E^(-06)) identified were TCA cycle (z-score = -4.123, p = 1.78E^(-07)), Superpathway of inositol phosphate compounds (z = -2.593, p = 1.13E^(-07)), Phosphoinositide biosynthesis (z = -2.286 p = 1.92 E-^(07)), IGF1 signalling (z = -2.4 p = 4.94E^(-07)) and Estrogen Receptor signalling (z = -2.069 p = 5.09 E^(-07)). The only upregulated canonical pathway identified which fitted these significance criteria was EIF signalling (z = 3.543 p = 3.84E^(-23)).
