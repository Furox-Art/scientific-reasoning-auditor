# Source-statistic preparation development protocol

Frozen before parser changes and before running the updated engine.
This is a post-hoc development follow-up to the frozen twelve-paper execution
audit, not a held-out benchmark or external preregistration. Old results and
sources are not rewritten.

The complete normalized text of DOI 10.1371/journal.pone.0288477 was read by the
organizing assistant, including methods/results/discussion/references. Original
figure images, supplements, raw observations and analysis code were not read
or executed. This is model reading, not independent human expert assessment.
Methods explicitly report Kruskal-Wallis tests and Bonferroni-adjusted Dunn
comparisons; a chi-square-looking label does not establish Pearson's test,
an exact central chi-square null distribution or unadjusted p-values.

Three source triplets are frozen with exact source hashes and offsets, in body
order. Evaluate recovery of literal test/reference notation, statistic, df and
p relation/value; require default alternative=unknown, df_precision=unknown,
requires_confirmation=true and checks_executed=false. No test direction,
correction suitability or exact df is inferred from prose. Retain failures.
Count development extraction recovery separately from scientific accuracy.

Execute the three unchanged draft checks explicitly to verify abstention.
For a separate, explicitly conditional demonstration, copy each draft and
declare upper central chi-square reference with exact df=2. The reference
calculation uses exp(-x/2), the df=2 central chi-square survival function,
evaluated independently of SciPy with 60-digit Decimal exponentiation.
This is a caller-defined mathematical scenario, not a verified interpretation
of the paper. All scientific-error labels and mapping-confirmation fields
remain null/false. Report both agreeing and disagreeing conditional results;
do not equate a discrepancy with a confirmed publication error.
The printed rounding convention and asymptotic/corrected reference suitability
require independent confirmation. No human identities or labels are generated.

Run the updated preparer over all twelve original frozen source snapshots
without replacing any paper. Report coverage and all unknown/unrequested work.
Do not claim representative multi-field error detection, independent gold
accuracy or a retrospective improvement to the original 0.10.0 first result.
